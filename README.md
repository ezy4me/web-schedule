# Учебное расписание

Веб-приложение для просмотра учебного расписания с фильтрацией по календарным датам (React + Tailwind CSS + date-fns + Lucide Icons).

## Запуск

```bash
npm install
npm run dev        # режим разработки (http://localhost:5180)
npm run build      # production-сборка в dist/
npm run preview    # предпросмотр собранного приложения (http://localhost:5181/web-schedule/)
```

## Деплой на GitHub Pages

Сайт публикуется автоматически через GitHub Actions (`.github/workflows/deploy.yml`) при пуше в `main`:

**https://ezy4me.github.io/web-schedule/**

Требования:
- В настройках репозитория **Settings → Pages** источник должен быть **GitHub Actions** (`build_type: workflow`).
- В **Settings → Actions → General** разрешены Actions (Workflow permissions: read and write).
- База пути `base: '/web-schedule/'` задана в `vite.config.js` (совпадает с именем репозитория).

## Источник данных

Все данные находятся в `src/data/schedule.js`:

- `odd_week` — нечётные недели (базовые даты 07.09, 21.09, 05.10, 19.10, 02.11)
- `even_week` — чётные недели (базовые даты 01.09–06.09, 14.09, 28.09, 12.10, 26.10, 09.11)
- `single_events` — разовые занятия (02.11, 12.11, 13.11, 07.12) — заменяют регулярные
- `SPECIAL_PAIRS` — пары с особыми условиями (notes, напр. `+17.11, 01.12, 15.12`), показываются только в перечисленные даты

## Логика недель

Тип недели определяется по номеру недели от начала выбранного семестра (неделя 0 = чётная, неделя 1 = нечётная):

- осенний семестр — с 1 сентября по 31 декабря;
- весенний семестр — с 1 января по 30 июня.

- дата из `single_events` → особый день
- нечётная неделя → пары из `odd_week`
- чётная неделя → пары из `even_week`

Реализация — в `src/utils/schedule.js` (функции `getSemesterRange`, `getWeekType`).

## Возможности

- Переключатель семестра (осенний / весенний): лента, календарь и статистика показывают только выбранный семестр, выбор сохраняется в URL
- Горизонтальная лента дней + всплывающий календарь в границах семестра (сентябрь–декабрь или январь–июнь), лента открывается на актуальной неделе
- Быстрые кнопки: «Сегодня», «Завтра», «Текущая неделя»
- Индикатор типа недели (Нечётная / Чётная / Особый день)
- Фильтры: группа, тип занятия (`лек` / `пр` / `л.р.`), поиск по дисциплине/аудитории
- Красивые кастомные select-компоненты
- Карточки пар, отсортированные по времени, с цветными бейджами типов
- Пустое состояние «В этот день пар нет»
- Mobile-first адаптивность: нижняя навигация, крупные тач-цели, календарь-диалог, шторка настроек
- **Выбор расписания**: выпадающий список с расписаниями преподавателей из `public/`
- **Загрузка расписания из своего JSON-файла** (кнопка «Свой JSON»)
- **Настройки** (сохраняются в браузере): преподаватель по умолчанию, автовыбор семестра, компактные карточки, вид по умолчанию, список горячих клавиш
- **Светлая и тёмная темы**, цвет системной панели подстраивается под тему

## Статистика

Отдельная страница с фильтрами по группе, преподавателю и периоду (семестр, остаток, конкретный месяц):

- **Обзор** — пары, аудиторная нагрузка, предметы, прогресс семестра, потоковые лекции, нагрузка по неделям/дням/времени, наблюдения
- **Графики** — донат-диаграммы по видам занятий и предметам, накопительная нагрузка, столбцы по месяцам, прогресс семестра, теплокарта «день × время», топ аудиторий и групп, инсайты
- **Разрезы** — таблица по группам, предметам, типам, аудиториям и преподавателям, с сортировкой, поиском и раскрытием деталей
- **Календарь** — месяцы семестра с интенсивностью по дням, переход в расписание по клику
- **Осталось** — список оставшихся пар по дням с ближайшей парой
- Экспорт выбранной выборки в `.ics`

## Оформление

Дизайн намеренно спокойный: тёплая бумажная основа (stone/paper), чернильный текст, один акцент — глина (clay). Никаких сине-фиолетовых градиентов, свечения и стеклянных панелей. Графики используют приглушённую «типографскую» палитру (`CHART_COLORS` в `src/components/Charts.jsx`), цвета видов занятий заданы в `src/constants.js`.

## Готовые файлы расписания

В папке `public/` лежат расписания, которые можно выбрать в интерфейсе:

- `maximov.json` — расписание Максимова Р.С. (по умолчанию, осенний и весенний семестры)
- `shumilkin.json` — расписание Шумилкина А.О. (осенний и весенний семестры)
- `gimadeev.json` — расписание Гимадеева И.Ф. (осенний и весенний семестры)
- `valova.json` — расписание Валовой П.А. (осенний семестр)

Чтобы добавить новое расписание, положите файл в `public/` и добавьте его в массив `SCHEDULE_SOURCES` в `src/App.jsx`.

## Формат загружаемого JSON

Приложение поддерживает два формата.

### 1. Плоский список пар с датами (рекомендуемый)

Массив объектов, где у каждой пары указан явный список дат:

```json
[
  {
    "day": "Понедельник",
    "time": "08:00",
    "dates": ["07.09", "21.09", "05.10", "19.10", "02.11"],
    "group": "4433",
    "type": "л.р.",
    "subject": "Проектирование и разработка интерфейсов пользователя",
    "room": "7 / 219"
  }
]
```

- `group` может содержать несколько групп через запятую: `"4433, 4435, 4437, 4438"`
- `dates` — список дат `ДД.ММ`, когда идёт занятие

### 2. Недельный формат

```json
{
  "odd_week": { "1": [ { "time": "08:00", "schedule": [ { "group": "ИС-21", "subject": "...", "type": "лек", "room": "..." } ] } ] },
  "even_week": { ... },
  "single_events": { "02.11": [ { ... } ] },
  "special_pairs": [ { "time": "15:10", "group": "ИС-21", "subject": "...", "type": "пр", "room": "...", "notes": "+17.11, 01.12, 15.12" } ],
  "single_event_dates": ["02.11", "12.11", "13.11", "07.12"],
  "groups": ["ИС-21", "ИС-22"]
}
```

Примеры файлов в формате 1 — `public/shumilkin.json` и `public/maximov.json`.
