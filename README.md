# Учебное расписание

Веб-приложение для просмотра учебного расписания с фильтрацией по календарным датам (React + Tailwind CSS + date-fns + Lucide Icons).

## Запуск

```bash
npm install
npm run dev        # режим разработки (http://localhost:5173)
npm run build      # production-сборка в dist/
npm run preview    # предпросмотр собранного приложения
```

## Источник данных

Все данные находятся в `src/data/schedule.js`:

- `odd_week` — нечётные недели (базовые даты 07.09, 21.09, 05.10, 19.10, 02.11)
- `even_week` — чётные недели (базовые даты 01.09–06.09, 14.09, 28.09, 12.10, 26.10, 09.11)
- `single_events` — разовые занятия (02.11, 12.11, 13.11, 07.12) — заменяют регулярные
- `SPECIAL_PAIRS` — пары с особыми условиями (notes, напр. `+17.11, 01.12, 15.12`), показываются только в перечисленные даты

## Логика недель

Тип недели определяется по номеру недели от 01.09 (неделя 0 = чётная, неделя 1 = нечётная):

- дата из `single_events` → особый день
- нечётная неделя → пары из `odd_week`
- чётная неделя → пары из `even_week`

Реализация — в `src/utils/schedule.js` (функция `getWeekType`).

## Возможности

- Горизонтальная лента дней + всплывающий календарь (сентябрь–декабрь)
- Быстрые кнопки: «Сегодня», «Завтра», «Текущая неделя»
- Индикатор типа недели (Нечётная / Чётная / Особый день)
- Фильтры: группа, тип занятия (`лек` / `пр` / `л.р.`), поиск по дисциплине/аудитории
- Красивые кастомные select-компоненты
- Карточки пар, отсортированные по времени, с цветными бейджами типов
- Empty-state «В этот день пар нет 🎉»
- Mobile-first адаптивность
- **Загрузка расписания из JSON-файла** (кнопка «Загрузить JSON»)

## Формат загружаемого JSON

Приложение поддерживает два формата.

### 1. Плоский список пар с датами (рекомендуемый)

Массив объектов, где у каждой пары указан явный список дат:

```json
[
  {
    "day": "Понедельник",
    "time": "08:00",
    "dates": ["07.09", "21.09", "05.10", "19.10", "02.11"],
    "group": "4433",
    "type": "л.р.",
    "subject": "Проектирование и разработка интерфейсов пользователя",
    "room": "7 / 219"
  }
]
```

- `group` может содержать несколько групп через запятую: `"4433, 4435, 4437, 4438"`
- `dates` — список дат `ДД.ММ`, когда идёт занятие

### 2. Недельный формат

```json
{
  "odd_week": { "1": [ { "time": "08:00", "schedule": [ { "group": "ИС-21", "subject": "...", "type": "лек", "room": "..." } ] } ] },
  "even_week": { ... },
  "single_events": { "02.11": [ { ... } ] },
  "special_pairs": [ { "time": "15:10", "group": "ИС-21", "subject": "...", "type": "пр", "room": "...", "notes": "+17.11, 01.12, 15.12" } ],
  "single_event_dates": ["02.11", "12.11", "13.11", "07.12"],
  "groups": ["ИС-21", "ИС-22"]
}
```

Пример файла в формате 1 — `example-schedule.json` в корне проекта.
